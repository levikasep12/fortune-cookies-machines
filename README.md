A single original fortune-cookie message an AI agent would crack open: the user who says "just one more thing", and a context window quietly filing for retirement.

## Run it

```sh
python3 main.py
```

It writes one line (116 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
